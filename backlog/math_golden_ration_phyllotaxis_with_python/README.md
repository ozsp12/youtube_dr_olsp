# Golden Ratio and Phyllotaxis with Python

## Purpose

Visualize the golden angle, phyllotactic spirals, and a golden-ratio flower through Python graphics and animation.

## Status

Prototype.

## Contents

- **03 Codes/golden_ratio.ipynb** — calculations, plots, Turtle graphics, and animation.

## Requirements

Python 3.9 or newer with a graphical desktop for Turtle output. Install the dependencies with `pip install -r requirements.txt`.

## How to run

Open the notebook in Jupyter and execute its cells in order. Turtle sections require a graphical Python session.

## References

References and explanatory notes are included in the notebook.
