# Python Submatrix Algorithm

## Purpose

Enumerate every contiguous submatrix of a requested size within a NumPy matrix.

## Status

Prototype.

## Contents

- **Submatrizes.py** — implementation and a small example matrix.

## Requirements

Python 3.8 or newer. Install the dependencies with `pip install -r requirements.txt`.

## How to run

Run `python Submatrizes.py` from this directory.

## References

The implementation is self-contained.
